An outreach system that does the repetitive work and leaves the judgement to a person

Problem
Good cold outreach needs research on every prospect. Templated mass emails get ignored or flagged as spam, and doing it by hand does not scale.
What I built
Site Auditor reads a prospect’s website and produces structured findings. A prompt I wrote turns those findings into a short, specific email or message. A rotation tool then spreads the sending across several mailboxes under daily caps.
Where AI stops
The model drafts from real findings. A person checks every claim against the actual page and decides what gets sent. The model never sends anything.
What went wrong first
The first sends landed in spam. I traced it to a few phrases in my own template and to ramping volume too fast, so sends are now paced, the wording is plainer, and mailboxes rotate under daily caps. I am still isolating how much was wording and how much was sender reputation.
Result
Run on a real first wave: 90+ personalised emails, 6 to 7 real conversations started, and one reaching a quote.
  1. AuditSite Auditor reads the site: stack, security, findability, trust signals
  2. StructureFindings exported as JSON an LLM can read
  3. PromptA written prompt sets role, tone and what the model may claim
  4. ReviewI verify every point against the real page, then edit
  5. SendThe tracker spreads sends across mailboxes under daily caps

Under the hood

  • The prompt is a contract: plain text only, a confident but warm tone, no fake-casual openers, short sentences, and a fixed four-part shape of hook, problems framed softly, proof, and a soft close.
  • It has to say so plainly when a metric is genuinely fine, so a message never invents problems to sound useful.
  • The audit is read-only. It fetches public URLs and records whether something is reachable, never what it contains.
  • Sending stays manual and every mailbox has a daily cap, so a person is always accountable and no sender reputation gets burned.
  • I found and fixed an HTML-injection bug in my own extension: page titles were being inserted unescaped. They are escaped now.
  • Known limit: the tracker only schedules while its tab is open. Everything runs locally and no passwords are stored.

Browser tool, runs locally

Outreach Rotation Tracker

Spreads a day’s contacts evenly across several company mailboxes in round-robin order and enforces a daily cap on each, so no inbox carries the whole load. Imports spreadsheets and schedules timed batches, for example 40 emails at noon and 40 at 4 pm.

HTML, CSS, JavaScript

The real tool running on fictional contacts. Sample data.

function assignBatch(contacts, label) {
  let ptr = state.rrPointer;                    // keeps rotating across batches
  contacts.forEach(c => {
    let tries = 0;
    while (tries < state.mailboxes.length) {
      const mb = state.mailboxes[ptr % state.mailboxes.length];
      if (mb.sentToday < mb.cap) {              // skip any mailbox at its daily cap
        c.assigned = mb.email; mb.sentToday += 1; ptr++;
        break;
      }
      ptr++; tries++;
    }
    if (tries >= state.mailboxes.length) c.status = 'no-capacity';
  });
  state.rrPointer = ptr;
}
