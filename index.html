Browser tool, runs locally

Outreach Rotation Tracker

Automates the daily sending plan: spreads a day’s contacts evenly across several company mailboxes in round-robin order and enforces a daily cap on each, so no inbox carries the whole load. Imports spreadsheets with column mapping and schedules timed batches, for example 40 emails at noon and 40 at 4 pm. Sending stays manual and no passwords are stored.

HTML, CSS, JavaScript

The real tool running on fictional contacts. Sample data.

function assignBatch(contacts, label) {
  let ptr = state.rrPointer;                    // keeps rotating across batches
  contacts.forEach(c => {
    let tries = 0;
    while (tries < state.mailboxes.length) {
      const mb = state.mailboxes[ptr % state.mailboxes.length];
      if (mb.sentToday < mb.cap) {              // skip any mailbox at its daily cap
        c.assigned = mb.email; mb.sentToday += 1; ptr++;
        break;
      }
      ptr++; tries++;
    }
    if (tries >= state.mailboxes.length) c.status = 'no-capacity';
  });
  state.rrPointer = ptr;
}
